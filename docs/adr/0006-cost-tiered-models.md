# Models are tiered by how much judgment each role needs

To control cost, each role defaults to the cheapest model that can do it well: Opus for Shape and for per-task plans (small output, highest leverage), Sonnet for Implement and for review and verification in Prove, Haiku for mechanical work (labels, GitHub operations), and no model at all for running checks, which is a script. The Intent interview runs in the human's own session. The project config can override any subagent's model (`models`); a phase skill's own model is fixed in its frontmatter and applies only to the turn that invokes it. Per-phase usage logging is deferred: a skill cannot read its own token usage, so cost is read from Claude Code's usage views for now.
